# ChatDS Desktop Windows 测试版

下载 `.exe` 安装到当前 Windows 用户，或解压 `.zip` 后运行 `ChatDS.exe`。两个版本使用同一份本机配置和聊天记录。安装包未做 Windows 代码签名，下载文件的 SHA-256 可与同页的 `SHA256SUMS.txt` 比对。

安装时选择已有 NapCat 或让 ChatDS 在首次启动时下载并校验 v4.18.42。QQ 模式需要 Windows QQ 客户端。用手机 QQ 扫码确认后，应用会核对账号并连接消息接口。以后打开 ChatDS 会检查并启动已关联的 NapCat。ZIP 版可在首次启动页下载、导入离线 ZIP、选择已有目录，或选择「仅使用桌面聊天」。

进入「环境配置」填写模型信息并点「测试通过后保存」，然后进入聊天。默认开启纯陪伴模式，支持连续补充、等待和结束对话。

想核实最近的公开消息时，切换到「受控助理」，点聊天栏的网页读取状态，在工具页开启「阅读公开网页」。回到聊天后可以请小鱼查官网。回复下方会标出实际读取过的站点，有失败时会显示具体原因。

首次扫码后允许该 QQ 的好友私聊。可以关闭这个选项，或单独添加允许的 QQ 和群。设置个人主号后可在主号私聊中共享桌面记忆。已有 OneBot 服务也可手动连接。Docker 仅用于可选的隔离脚本工具。

本次验收使用本机模拟的 NapCat 登录、OneBot 私聊和发送回执。真实 QQ 账号登录、消息投递和空间发布仍待验证。

反馈陪聊问题时，请附一段脱敏后的消息顺序，标出谁在说话、谁被 @ 或引用，以及你希望小鱼在哪一条回复或保持安静。请保留 API Key、OneBot 令牌和登录二维码的私密性。
